# cond-head-embed-served-form
Addresses: the output head and the input embedding are vocabulary-wide matrices whose error no in-body compensator repairs; their served form depends on config fields the producer did not intend to set. Measured as: the head's and embedding's dtype and grid as bound by a loaded server, beside the producer's intent; per vocabulary row, the head's rounding error at the body's grid and at a finer grid.
Mechanism: The embedding and the head are not body Linears and are not served like them, so fix their form explicitly. Store the head as its own name-matched config group, which takes precedence over a class-wide server rule. Give the head a finer grid than a narrow body grid. If the server builds the embedding without a quantization config, it reads the table as stored; then write the dequantized values of the intended grid, not a packed tensor. Untie a tied embedding and head first, so the head runs its own kernel. Copy every other tensor byte for byte; re-read the result to confirm which tensors changed.
Effect: the served head and embedding forms equal the intended ones (read back from the server); at a finer head grid the head's per-row rounding error falls; every other tensor is unchanged byte for byte.
Preconditions: the server's rules for name-matched versus class-matched config groups and for a quantized embedding are known for the exact serving version (they differ between versions); the head can be untied without changing the rest of the checkpoint; the body's scheme is fixed first.
Inference overhead: none beyond the head grid's own kernel; a dequantized embedding costs the memory of a full-precision table.
Pitfalls: a config with a cache or activation scheme the producer never set can make the server quantize an unintended tensor, without a record; pass the serving dtypes explicitly and read back what the engine bound. Second: head tensors shared across builds of one model carry one bug into every build; check the head's form separately. Third: with the tie flag left on, the loader re-ties the head to the embedding; set the flag off and give the head its own tensor.
Source: the head and embedding form of the GSQ release: Dadgarnia et al., "GSQ: Highly-Accurate Low-Precision Scalar Quantization for LLMs via Gumbel-Softmax Sampling", arXiv 2026. https://arxiv.org/abs/2604.18556 · code: https://github.com/IST-DASLab/GSQ ; how the server binds a name-matched group and a quantized embedding: serving engineering, no publication.
