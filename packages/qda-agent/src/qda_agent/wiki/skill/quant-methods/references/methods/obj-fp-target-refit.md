# obj-fp-target-refit
Addresses: quantization error accumulates block by block, and a symmetric local objective does not ask a layer to cancel its quantized upstream's drift. Measured as: per layer, the relative gap ‖X̃ − X‖/‖X‖ between the full-precision input X and the quantized-stream input X̃, growing with depth, and the layer output error ‖W X − Ŵ X̃‖.
Mechanism: Stock GPTQ minimises ‖(W − Ŵ) X̃‖² on the inputs X̃ inside the partially quantized model; the asymmetric objective minimises ‖W X − Ŵ X̃‖², i.e. it reproduces the full-precision output from the layer's actual inputs. GPTAQ keeps GPTQ's column loop and adds one residual term. With ΔX = X − X̃, U the upper Cholesky factor of the damped H̃⁻¹, and P = α · triu₁(ΔX X̃ᵀ Uᵀ) U (strict upper triangle), quantizing column i updates each later column j by −e_i U_ij + w_i P_ij, where e_i = (w_i − q_i)/U_ii is GPTQ's scaled error and w_i the column before rounding. α scales the ΔX X̃ᵀ term. This library's variant (not in the paper): refit W_α = W − α (W C)(H̃ + λI)⁻¹ with C = (X̃ − X) X̃ᵀ, then run unmodified GPTQ (or a Hessian-priced grid search) on W_α under H̃; α = 0 is stock GPTQ, α = 1 the exact objective.
Effect: in the variant, per layer, the solved target moves from W X̃ to W X as α goes from zero to one, so the asymmetric output error ‖W X − Ŵ X̃‖² is what the solve minimises at α = 1 with λ = 0, and its damped form with λ > 0; the weights move away from W along (W C)(H̃ + λI)⁻¹.
Preconditions: two activation caches per subgraph (fp stream and quantized stream), about three forwards per subgraph; the first quantized subgraph has C = 0.
Inference overhead: none
Pitfalls: the refit moves W before quantization, so a grid chosen on the original weights fits a tensor that no longer exists; observer-first is a different method. Second: at large alpha the correction, through the damped Hessian of the QUANTIZED stream, can move weights along directions the calibration does not constrain; alpha is the only bound. Third: when the upstream drift is mostly rounding noise, not a systematic shift, the refit fits calibration noise. Fourth: on the first subgraph the two caches are the same tensor, so the correction must be zero; a non-zero value means the two streams are built incorrectly.
Origin: Li et al. observed that sequential layer quantization fits each layer to the quantized prefix's output, so the activation deviation grows block by block; they targeted the original layer's output on the full-precision input instead.
Source: Li et al., "GPTAQ: Efficient Finetuning-Free Quantization for Asymmetric Calibration", ICML 2025. https://arxiv.org/abs/2504.02692 · code: https://github.com/Intelligent-Computing-Lab-Yale/GPTAQ
