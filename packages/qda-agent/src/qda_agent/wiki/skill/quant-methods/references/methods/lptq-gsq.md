# lptq-gsq
Addresses: at three bits, code choice is a combinatorial problem that greedy column-wise compensation does not search; after a fixed code assignment, further compensation does not reduce the per-layer output error. Measured as: per layer, the layer-output MSE of the column-wise assignment, and the decrease from moving codes within a small window of neighbouring levels.
Mechanism: Per decoder layer, GPTQ gives the initial codes (in the paper). Each weight gets logits over a small window of neighbouring integer codes. An annealed Gumbel-softmax samples the code (temperature down, logit scale up) and ends at a hard code. fp32 group scales train jointly. The loss is the layer (or attention sub-block) output MSE against the full-precision layer on the same inputs; the MLP stage takes the quantized attention output as input. This library's variant (not in the paper): a refinement step that starts from any quantized checkpoint of the target format, not only a GPTQ one, keeps that format, freezes its zero points, and trains the codes and scales per block.
Effect: per layer, the relaxed layer-output MSE on the training inputs falls from the column-wise initialisation (in the paper), and the hard-code MSE is read after annealing; codes move within the window, and the group scales are re-learned in fp32.
Preconditions: a working GPTQ init at the target scheme (in the paper); cacheable per-layer inputs; enough calibration tokens for many optimizer steps per layer; the producer knows the architecture (attention vs MLP stage split per layer, which modules stay bf16, MoE routed-expert handling).
Inference overhead: none (plain grouped int, e.g. int3 g128 sym).
Pitfalls: the relaxation must be hard at the end. The soft (expected-code) forward reports a loss the exported checkpoint cannot reach; the gap grows with the stop temperature, so validate on the hard forward. Second: the learned fp32 group scales can be negative; a kernel or later scale-training stage that assumes positive scales accepts the checkpoint but computes a different function. Third: the code is a port; rebuild one layer with the reference implementation on identical inputs and compare codes and group scales.
Origin: Dadgarnia et al. observed that at two and three bits a one-shot solver commits each weight greedily in a fixed order. It does not revisit the error passed to later weights. They relax the level choice of each weight with Gumbel-Softmax, so codes and scales fit jointly and harden at the end.
Source: Dadgarnia et al., "GSQ: Highly-Accurate Low-Precision Scalar Quantization for LLMs via Gumbel-Softmax Sampling", arXiv 2026. https://arxiv.org/abs/2604.18556 · code: https://github.com/IST-DASLab/GSQ
