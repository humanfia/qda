# cond-awq-moe
Addresses: on a mixture-of-experts layer, a dense scale-migration mapping either misses the router (the router then reads rescaled inputs with unscaled weights) or prices each expert's scale on tokens the router never sends it. Measured as: per layer, the fraction of positions whose top-k expert set differs between the folded and the original model; per expert, the routed-token count beside the token count of its statistic.
Mechanism: MoE-safe activation-aware smoothing. The gate/up inputs of all experts share one layer-wide scale; this scale is folded into the post-attention norm and balanced into every reader of that norm (router, shared expert, all experts). Each expert's down_proj gets a private scale folded from that expert's own up_proj rows. Each expert's scale search is priced only on the tokens routed to it.
Effect: the router and the shared expert absorb the same inverse scale as the experts, so the folded model's top-k selection equals the original's in exact arithmetic; in the stored dtype a selection near a tie can still flip; each expert's scale statistic is taken only on its routed tokens.
Preconditions: experts stored as separate linears (or unfused before smoothing); the router and shared expert read the same normed input and can absorb the inverse scale; every expert receives some routed calibration tokens (otherwise fall back to the all-token statistic).
Inference overhead: none (scales folded offline).
Pitfalls: a name-based mapping table misses a router that is not an nn.Linear or that reads the stream before the norm. The fold is then exact for the experts and wrong for the router, so tokens reach different experts while each expert's output is unchanged. Second: an expert with no routed calibration token has an empty statistic; an implicit fallback to the all-token statistic is a different mechanism from this card's. Log the routed-token count per expert and make the fallback explicit. Third: rounding the folded weights to the stored dtype can flip the discrete top-k router selection; top-k agreement between the folded and the original model on calibration tokens is the diagnostic, if one is wanted.
Origin: Fu et al. (EAQuant) observed that the experts of one routed layer have their large-magnitude input channels in largely the same positions. So one layer-level vector can serve every expert and the router, and only a shared vector folds into the one normalization before the experts.
Source: Lin et al., "AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration", MLSys 2024. https://arxiv.org/abs/2306.00978 · code: https://github.com/mit-han-lab/llm-awq ; the layer-shared scale balanced into the router and every expert: Fu et al., "EAQuant: Enhancing Post-Training Quantization for MoE Models via Expert-Aware Optimization", arXiv 2025. https://arxiv.org/abs/2506.13329 ; an expert's scale priced on its routed tokens: Hu et al., "MoEQuant: Enhancing Quantization for Mixture-of-Experts Large Language Models via Expert-Balanced Sampling and Affinity Guidance", ICML 2025. https://arxiv.org/abs/2505.03804
