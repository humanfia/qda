# mlp-intermediate-channel-outliers
Observable: at the input of the projection that reads the MLP's intermediate activation, a few channels are magnitude outliers. The set is stable across tokens and across texts. It has the same shape as the residual-stream condition, in a place where it is harder to remove. The intermediate sits behind an elementwise nonlinearity and a product of two projections. So there is no norm in front of it to fold a transform into, and no linear path along which an offline rotation cancels.
How to see it on your own model: hook the intermediate activation, take the per-channel mean of |x| over a calibration batch, and sort it. Separately, histogram absmax/rms per quantization group of that projection's input columns. Compare both with the same statistics at a projection that reads the residual stream directly. The phenomenon is present when the intermediate's channel concentration is comparable to or above the stream's. Also record if the loud channels coincide with the channels where the gating branch saturates. This tells you if the concentration comes from the gate or from the value branch. Each reading needs one forward hook and no build. A residual-stream rotation does nothing here, because the intermediate is not the residual stream.
Cards: rot-channel-perm, cond-awq, grid-clip-search
