# lptq-qat-kd
Addresses: every one-shot method optimises a local surrogate, so a model-level output gap remains; at low bit widths, scale-only or block-local freedom is small. Measured as: on a fixed text, the per-layer hidden-state distance of a one-shot build to the source along depth.
Mechanism: Full quantization-aware training. All weights (and quantizer scales and zero points, optionally the clipping) train end to end through fake quantization with a straight-through estimator. The loss is a divergence between the full next-token distributions of the student and the full-precision source, often on source-generated text. Vendors also ship such checkpoints.
Effect: all weights, scales and zero points move to lower the model-level distillation objective on the training text from its initial value; the stored bits are those of the chosen grouping.
Preconditions: compute and memory to train the full model (optimizer states for all weights); teacher logits or a live teacher; a fake-quant forward that matches the serving kernel scheme (group size, symmetric/asymmetric).
Inference overhead: none (a standard grouped integer checkpoint of the target scheme).
Pitfalls: with the straight-through estimator, a trained weight can sit just inside a code boundary; a later stage that re-rounds with changed scales can push it across, and a later stage that freezes the codes changes only the dequantized values. Second: on source-generated text, the objective depends on the source decoding settings; record them with the method. Third: a trainer can use a finer grouping than the format allows; read the bits per weight from the saved tensors, not from the training configuration.
Source: Liu et al., "LLM-QAT: Data-Free Quantization Aware Training for Large Language Models", arXiv 2023. https://arxiv.org/abs/2305.17888 · code: https://github.com/facebookresearch/LLM-QAT; Du et al., "BitDistiller: Unleashing the Potential of Sub-4-Bit LLMs via Self-Distillation", arXiv 2024. https://arxiv.org/abs/2402.10631 · code: https://github.com/DD-DuDa/BitDistiller
