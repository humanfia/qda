# rot-channel-perm
Addresses: channel order is arbitrary, so one heavy channel can share a quantization group with ordinary channels, and its range rounds them coarsely. Measured as: per group of the readers' input columns, absmax/rms before and after the reorder.
Mechanism: Reorder channels offline so that each quantization group spans a narrow magnitude band. Apply one permutation of the hidden channels to every reader's input columns and every writer's output rows (embedding, norms, readers, writers, untied head). Apply one permutation per layer to the MLP intermediate (gate/up rows, down columns). The function is unchanged.
Effect: per-group range statistics fall for groups that held mixed channels; weights and function are unchanged (a pure index permutation).
Preconditions: hidden and intermediate sizes are multiples of the group size; every reader and writer of the permuted dimension is enumerable; dimensions paired by RoPE or read by a per-head norm are not moved.
Inference overhead: none (absorbed offline).
Pitfalls: do the reorder as a pure index operation, never fused with a cast or a scale; a missed reader breaks the identity. Second: a fused serving projection stores several logical matrices in one tensor; a permutation of the whole tensor moves rows across their boundaries, and the model still runs. Permute each logical unit, and read the actual layout from the modelling code.
Origin: Lin et al. (DuQuant) observed that after a block-diagonal rotation one block keeps more outlier mass than the others. A permutation decides which block each outlier channel lands in, which no block-diagonal transform can do.
Source: Yuan et al., "RPTQ: Reorder-based Post-training Quantization for Large Language Models", 2023. https://arxiv.org/abs/2304.01089 · Lin et al., "DuQuant: Distributing Outliers via Dual Transformation Makes Stronger Quantized LLMs", NeurIPS 2024. https://arxiv.org/abs/2406.01721 · code: https://github.com/Hsu1023/DuQuant ; in-group range set by a few channels: Liang et al., "ParoQuant: Pairwise Rotation Quantization for Efficient Reasoning LLM Inference", ICLR 2026. https://arxiv.org/abs/2511.10645
