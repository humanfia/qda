# obj-gradient-token-weights
Addresses: the effect of a module's output error on the model's output varies per token and per module; a uniform H ignores this. Measured as: per token and module, ‖∂ℓ/∂z_{t,m}‖² from one backward pass of the source, and its concentration (the share held by the top tokens).
Mechanism: One backward pass of the bf16 source gives, per token t, the squared gradient of the end loss w.r.t. each output channel of a module, (∂ℓ/∂z_{t,j})², averaged over each group g of consecutive output channels into w_{t,g}. Each group's rows get the Hessian H_g = Σ_t w_{t,g} x_t x_tᵀ; the layer-wise solve runs unchanged. The loss ℓ is the text's own next-token NLL (GuidedQuant). This library's variant (not in the paper): one weight per token per group of modules that read one input (the sum of their squared output gradients), normalised to mean 1 per layer and group and clipped at a multiple of the mean.
Effect: H's mass moves to the tokens with a large output gradient.
Preconditions: a full backward through the source fits in memory (gradient checkpointing / micro-batching for large models); calibration chunks reproducible and order-stable (some pipelines reorder chunks).
Inference overhead: none
Pitfalls: when the weights concentrate on few tokens, the build approaches a build calibrated on those tokens alone; read the concentration on the target model. Second: reordering, re-chunking or re-padding the calibration stream after the weight pass misaligns the weights; record a stream hash with the weights.
Origin: Kim et al. observed that the end loss is not equally sensitive to every weight; GuidedQuant puts this sensitivity into the layer-wise objective as a per-token weight on the second moment.
Source: Kim et al., "GuidedQuant: Large Language Model Quantization via Exploiting End Loss Guidance", ICML 2025. https://arxiv.org/abs/2505.07004 · code: https://github.com/snu-mllab/GuidedQuant ; Fisher-weighted sensitivity: Kim et al., "SqueezeLLM: Dense-and-Sparse Quantization", ICML 2024. https://arxiv.org/abs/2306.07629 · code: https://github.com/SqueezeAILab/SqueezeLLM
