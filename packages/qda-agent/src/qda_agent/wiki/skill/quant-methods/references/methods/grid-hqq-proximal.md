# grid-hqq-proximal
Addresses: a least-squares fit of a group's scale is pulled by the few largest residuals, entries the grid cannot represent anyway. Measured as: per group, the distribution of dequantization residuals |w − s(q − z)| -- the share of the squared residual held by the top entries.
Mechanism: Choose each group's scale and zero point by minimising || W - s(q - z) ||_p with p below one instead of the squared norm. A half-quadratic split introduces an auxiliary variable for the residual. The solver alternates a closed-form shrinkage on that variable with a closed-form update of the zero point, and re-rounds the codes each sweep. The scale stays at its min/max initialisation (an optional grid search can set it once before the sweeps). The procedure reads only the weight tensor.
Effect: the sub-quadratic penalty ‖W − s(q − z)‖_p lowers the weight of a group's few largest residuals in the fit; no calibration statistic enters.
Preconditions: no structural precondition and no calibration pass, so the method is usable where no representative text exists. The container must carry a zero point, because the zero point is the main variable the solver moves. The solver's sweeps must be bounded, because the objective is not convex and the iteration has no termination guarantee.
Inference overhead: none (an ordinary grouped integer checkpoint).
Pitfalls: the loss is on the weight residual and uses no activation statistic. So the grid fits the bulk of the weights, even if the sacrificed entries are in channels the layer reads. The method cannot fix this; where calibration text exists, the weighted alternatives price what the layer reads. Second: the non-convex problem makes the result depend on the initialisation and the sweep count; builds with different sweep budgets are different methods, so record both. Third: the method is fast enough to become a default on all modules, including a router or a head. There the weight residual carries no information about the routing decision or the output distribution. Fourth: the solver's zero point is a float; round it onto the container's integer zero-point grid, inside its range after packing, before the codes are chosen. Otherwise the codes fit a grid the container cannot store.
Origin: Badri and Shaji observed that a group's reconstruction residual is heavy-tailed, so a squared-error fit of scale and zero is pulled toward a few outlying weights. A sub-quadratic penalty stops those weights from dominating, and half-quadratic splitting turns it into alternating closed-form updates without gradients or calibration data.
Source: Badri & Shaji, "Half-Quadratic Quantization of Large Machine Learning Models", 2023. https://mobiusml.github.io/hqq_blog/ · code: https://github.com/mobiusml/hqq
