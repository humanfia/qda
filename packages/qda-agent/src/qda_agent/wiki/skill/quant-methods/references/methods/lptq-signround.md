# lptq-signround
Addresses: round-to-nearest and fixed clipping do not minimise the block-output error; a layer-wise closed-form solver cannot trade per-weight rounding against per-group range in a block. Measured as: per block, the block-output MSE of round-to-nearest against the full-precision block on calibration inputs.
Mechanism: One decoder block at a time, signed-gradient descent learns, for every Linear, a per-weight rounding offset in [-0.5, 0.5] and per-group min/max clipping factors. The loss is the block-output MSE against the full-precision block on cached calibration inputs; the lowest-loss step is kept. The result is plain grouped int (e.g. int4 g128 sym) with no extra tensors. The block-local loss does not see the model output.
Effect: per block, the block-output MSE is at most round-to-nearest's on the minibatch each step is compared on (step zero is a candidate); on the whole tuning set this holds only when every step is compared on all of it; each code is the nearest or second-nearest level; the stored format is unchanged.
Preconditions: decoder blocks run in isolation on cached inputs (the sequential pipeline knows the block boundary); per-block calibration inputs fit in memory; the target format is a plain grouped integer scheme.
Inference overhead: none (same layout and kernel as GPTQ/RTN at that scheme).
Pitfalls: the offset is bounded to one code step, so each weight takes one of its two nearest codes; when the grid is too coarse for the group range, many offsets can sit at their bound and the clipping factors then do most of the work; freeze one of the two to attribute the result. Second: a lowest-loss step selected on the tuning inputs fits those inputs; hold out part of the cached block inputs for the selection.
Origin: Cheng et al. observed that a code changes only when its rounding offset crosses the midpoint of its grid cell, so the search per weight is a bounded interval. Raw gradient magnitudes carry little usable scale information there, so a fixed-size signed step on the block-output error explores that interval evenly. The layers in a block interact in each rounding decision.
Source: Cheng et al., "Optimize Weight Rounding via Signed Gradient Descent for the Quantization of LLMs", EMNLP Findings 2024. https://arxiv.org/abs/2309.05516 · code: https://github.com/intel/auto-round
