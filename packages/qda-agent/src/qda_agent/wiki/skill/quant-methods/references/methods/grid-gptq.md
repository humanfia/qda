# grid-gptq
Addresses: correlated input channels make independent rounding errors add up in a layer's output. Measured as: per layer, the layer-output error tr(E H Eᵀ) of round-to-nearest beside the same error with H's off-diagonal removed; the difference is the part due to correlation.
Mechanism: GPTQ quantizes a layer column by column and pushes each column's rounding error onto the columns not yet quantized through the inverse calibration Hessian H = Σ x xᵀ (the OBS/OBQ update). It minimises tr(E H Eᵀ) per layer. Knobs: damping λ·mean(diag H) added before Cholesky, column order (static, or descending diag H; `group` order stores a per-module g_idx), and the grid source (observer, see grid-clip-search). The MoE variant solves stacked expert Hessians in batches, layer by layer.
Effect: the update compensates the correlated part of tr(E H Eᵀ), with no guarantee that every instance ends below round-to-nearest on the same grid. The weights move away from their originals, most along the directions the calibration excites least. As damping grows, the update shrinks toward zero (round-to-nearest).
Preconditions: a calibration forward pass through every quantized Linear; the damped H must be Cholesky-factorable for every module; act-order with g_idx is allowed only if the serving kernel accepts g_idx and the bit budget counts it.
Inference overhead: none (same tensors as RTN); g_idx order adds a gather per layer.
Pitfalls: if a module's damped Hessian does not factorise, an implementation can fall back to round-to-nearest for it. The checkpoint then passes all structural checks but contains modules the recipe does not describe. Raising that module's damping until it factorises removes the fallback, and a count of fallen-back modules shows whether any happened. Second: the damping is in the recipe and not in the config block a record shows, so two builds with identical quantization_config can be different solves; diff the recipes. Third: with damping raised far enough, a build labelled GPTQ is in effect a round-to-nearest build on the same grid.
Origin: Frantar et al. (GPTQ) observed that an error on one correlated input channel can be cancelled on the channels not yet rounded, and that the exact per-row greedy solver is costly. Because all rows share the input second moment, one fixed column order lets a single Cholesky factor of its inverse serve the whole matrix, with the updates applied in blocks.
